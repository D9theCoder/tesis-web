# Geist Sans

`geist-latin.woff2` is the unchanged variable Latin subset bundled with the
installed Next.js 16.3.1 package at
`next/dist/next-devtools/server/font/geist-latin.woff2`.

Upstream: [Vercel Geist](https://github.com/vercel/geist-font).
License: SIL Open Font License 1.1, included as `OFL.txt` from upstream.

The root layout loads this checked-in file through `next/font/local`; builds and
visitors do not need a font-provider connection. System fonts remain fallbacks
for unsupported characters and unsuccessful font loading.
